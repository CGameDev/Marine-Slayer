# Marine Slayer

**Marine Slayer** is a complete top-down sci-fi action shooter targeting **Xbox 360** through **Unity 5.4.1f1**.

The game uses the developer-owned licensed sci-fi asset pack supplied separately as a **local dependency**. The raw paid asset package is intentionally not stored in this public repository.

## Creative direction

Marine Slayer combines two high-level design influences:

- tactical, readable, top-down combat and positioning in the spirit of handheld/isometric military action shooters;
- fast, aggressive, forward-pressure combat, arena escalation, weapon swapping and resource-driven momentum associated with modern high-intensity shooters.

These are design inspirations only. The project must remain original. Do not copy protected characters, story, level layouts, names, dialogue, UI, audio, models, textures, logos or other expressive material from any commercial game.

## Primary target

- Engine: Unity 5.4.1f1
- Primary platform: Xbox 360
- Secondary development target: Windows Editor/standalone for iteration only
- Input: Xbox 360 controller first
- Camera: top-down / elevated tactical action camera
- Core mode: single-player campaign
- Secondary mode: local co-op / challenge mode only after campaign stability

## Repository policy

GitHub is the permanent project source of truth. Licensed paid source assets remain outside Git and are imported locally. Source code, scenes created for Marine Slayer, project-owned UI, configuration, documentation, tests and distributable project-owned content belong in this repository.

## Definition of success

Milestone 001 is not a prototype milestone. The target is a coherent, beginning-to-end playable game with a main menu, campaign, multiple distinct levels, complete combat loop, enemy progression, bosses, checkpoints/save progression, difficulty settings, pause/options, story/dialogue delivery, ending/credits, Xbox 360 build validation and documented target-hardware testing.
